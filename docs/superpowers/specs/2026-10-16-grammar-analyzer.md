# 英文语法批注工具：已确认设计

个人使用，代码采用现有 MIT 许可证开源。中文单页界面，原文保持词形、标点与顺序。按语法成分浅色框选，框外上下批注由短线准确连接。Everyone in the stadium felt nervous. 中 Everyone 蓝色主语、felt 红色系动词（feel－感到）、nervous 绿色表语（紧张的）。in the stadium 在详细模式标为后置定语；说明整个名词短语为主语。

输入英文句子或短段落（最多 300 词/6000 字符），粘贴后自动分析，提供手动分析、清空、示例。逐句翻译，整段翻译折叠。默认主干、详细结构切换。动词批注显示原形，原文不变。详情中解释时态与结构。无账号、历史、生词本、数据库。

Node.js 22+ 无运行时第三方依赖，原生 HTML/CSS/JS 前端与同源 Node HTTP 后端。仅监听 127.0.0.1，校验 Host/Origin，拒绝跨站调用。DeepSeek 密钥仅从环境读取。使用官方 OpenAI 兼容 chat/completions JSON 模式，模型可配置，当前默认 deepseek-flash。API 输出须校验所有原文片段拼接等于输入（只容许句间空白），标签白名单，长度边界，动词 lemma。AI 结果以文本节点呈现。没有密钥时仍能查看明确标注的内置示例，不伪造实时结果。

排版采用每个片段内部绑定标注与引线，按行共享英文基线；标签较长允许占宽/换行，不能碰撞相邻标注。长短语可拆成连续的同色片段，在移动端仍无横向溢出。不直接公开收费接口。GitHub Pages 可作为静态示例，实际分析需本地后端。交付开发分支和 PR，不自动合并。
