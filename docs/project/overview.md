# 项目概况

最后更新：2026-10-29（对应仓库 main 提交 676ecb0，含 PR #20–#28）

## 一句话
贴一句英文，网页会像老师在课本上批注一样，用不同颜色框出主语、谓语、宾语等成分，旁边写上中文意思和词的原形，标出时态和判断依据，最后给出整句翻译。

## 给谁用
- 说中文、正在学英语的人，覆盖全年龄段。界面和讲解都是中文。
- 先解决我自己学语法时的痛点：长句子读到一半就乱了。

## 定位
- 免费、开源。
- 没有服务器、没有数据库、没有统计代码。
- 每个用户在浏览器里填自己的 DeepSeek 密钥，费用由自己的 DeepSeek 账户承担。
- 相比直接问 AI，差异在于可视化：用颜色和框把句子结构变成一张图，更容易看懂、记住。
- 已知竞品：有道词典的长难句分析；直接问 ChatGPT 或 DeepSeek 也能得到类似讲解。

## 现在能做什么
- 主干视图：只框主语、谓语、宾语或表语。
- 详细视图：勾选「显示详细结构」后，定语、状语、补语也会显示。
- 点击彩色框，下方显示详细解释。
- 修饰高亮：详细视图里点定语、状语、补语，会高亮它修饰的词，下方显示「修饰：…」（PR #14）。
- 分离短语动词：`should give it up` 显示成 should give / it / up，两个红框共用 give up 的解释，说明只讲一遍；相邻的 give up 仍是一个框（PR #20、#23、#26）。
- 时态黄框：显示时态和语态，附「判断依据」；从句或并列分句时态不同时，用「；」分别列出。
- 多个句子逐句分析，可以展开查看整段翻译。
- 格式修正：AI 返回格式不对时，自动让模型修正一次；会多花一次用户额度，页面事先提示（PR #15）。
- 一键反馈：每句下面有「这句分析有问题？」按钮，请求失败时有「报告分析问题」。简单表单：选问题类型、写一两句、勾「我知道内容会公开」，点「去 GitHub 提交 →」，GitHub 新页面已填好，用户点 Create 提交。需要 GitHub 账号；不自动提交，不带密钥（PR #21、#22、#25）。内容超过 6000 字符时分两步：「① 复制反馈内容」→「② 打开 GitHub 粘贴 →」，GitHub 标题已带上，正文框写了怎么粘贴（PR #28）。
- 三步引导：拿密钥、存密钥、粘贴英文，完成的步骤会打勾。
- 「大字」开关：整页放大 1.25 倍，设置会记在本机。
- 内置例句（不填密钥也能看）：Tired learners who keep going every day will see the beauty of English grammar in the end.
- 输入上限：300 个英文单词、6000 个字符。
- 工具版本号（写进反馈）：`2026-10-28.2`（PR #28）。
